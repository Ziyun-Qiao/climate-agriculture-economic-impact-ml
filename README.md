# climate-agriculture-economic-impact-ml
Machine learning analysis for MSc dissertation on predicting the economic impacts of climate change on agriculture.

## Contents
- Jupyter Notebook containing data preprocessing, exploratory analysis, K-Means clustering, predictive modelling, hyperparameter optimisation, and evaluation.

## Dataset
Climate Change Impact on Agriculture 2024, obtained from Kaggle.

## Models
- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost
- Support Vector Regression

## Software
Python and Jupyter Notebook.
